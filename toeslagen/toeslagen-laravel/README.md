# Toeslagen (Laravel 11)
1. `composer create-project laravel/laravel toeslagen` en `cd toeslagen`
2. Kopieer alle mappen uit deze zip over je project heen (overschrijft User.php, bootstrap/app.php, routes/web.php, DatabaseSeeder.php)
3. Zet in `.env` je database (of laat SQLite staan)
4. `php artisan migrate --seed`
5. `php artisan serve` -> http://localhost:8000
